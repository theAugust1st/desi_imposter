## 🎯 Executive Summary

### What's New in V2

Desi Imposter V2 introduces **two major features** to enhance gameplay variety and content scalability:

1. **Category-Based Word Filtering** — Players can now filter words by thematic categories (Music, Politics, Movies, Sports, etc.) in addition to regional selection, enabling more focused and strategic gameplay.

2. **Downloadable Content Packs** — An extensible offline content system that allows users to download, manage, and play with curated word packs hosted on GitHub, expanding the game's vocabulary beyond the initial 205 built-in words.

### Problem Statement

**V1 Limitations:**
- **Limited Customization:** Players cannot filter by topic/theme, leading to unpredictable word variety
- **Static Content:** 205 words is insufficient for replay value; no mechanism to expand content without app updates
- **Rigid Word Pool:** No way to create specialized game modes (e.g., "Music Night" or "Bollywood Only")

**V2 Solutions:**
- Dual-filter system (Region + Category) for targeted gameplay
- GitHub-hosted content packs for infinite scalability
- Offline-first architecture maintained with AsyncStorage caching
- User-controlled pack management (download, enable/disable, delete)

### Goals

**Primary Goals:**
1. ✅ Enable category-based filtering alongside region selection
2. ✅ Implement downloadable content pack infrastructure
3. ✅ Maintain 100% offline playability after initial pack downloads
4. ✅ Preserve backward compatibility with V1 data and user experience

**Non-Goals:**
- ❌ Player profile improvements (deferred to V3)
- ❌ User-generated content packs (V2 uses curated packs only)
- ❌ Real-time multiplayer or online features
- ❌ In-app purchases or monetization

## 📊 Requirements & User Stories

### Feature 1: Category-Based Word Filtering

#### User Story 1.1: Category Selection
**As a** game host  
**I want to** select specific categories (e.g., Music, Movies, Politics)  
**So that** the game focuses on topics my group knows and enjoys  

**Acceptance Criteria:**
- [ ] Category picker UI component available on setup screen
- [ ] User can select 1 or more categories from available list
- [ ] Word count updates in real-time based on region + category filters
- [ ] Cannot start game without selecting at least 1 category
- [ ] Selected categories persist when returning to setup from "Play Again"

#### User Story 1.2: Regional + Categorical Filtering
**As a** game host  
**I want to** combine region and category filters (e.g., "Nepal + Music")  
**So that** I get words that match both criteria  

**Acceptance Criteria:**
- [ ] Word pool filters words where `regions` includes selected region(s) AND `category` matches selected category/categories
- [ ] Empty pool scenario displays helpful error message
- [ ] Word count display shows breakdown: "85 words (60 built-in + 25 from packs)"

#### User Story 1.3: Imposter Category Blindness
**As a** imposter  
**I want to** NOT see the category hint  
**So that** the game remains challenging  

**Acceptance Criteria:**
- [ ] Imposter card shows region/scope ONLY (no category information)
- [ ] Hint text does not explicitly mention the category
- [ ] Category filtering is transparent to gameplay phase

### Data Flow: Game Start with Packs

```
1. App Launch
   ├─▶ Load installed packs from AsyncStorage
   └─▶ Populate packWords[] in Zustand store

2. User Setup
   ├─▶ Select Regions (India, Nepal)
   ├─▶ Select Categories (Music, Movies)
   └─▶ Word count = filter(builtInWords + packWords, regions, categories)

3. Start Game
   ├─▶ buildWordPoolWithCategories(regions, categories, packWords)
   ├─▶ Filter by: word.regions ∩ selectedRegions AND word.category ∈ selectedCategories
   ├─▶ Exclude recently used words (usedWordIds)
   └─▶ Select random word from final pool

4. Distribution Phase
   └─▶ (Unchanged from V1)
```

**New Function:**

```typescript
/**
 * Build word pool with region AND category filtering
 * 
 * @param selectedRegions - User-selected regions
 * @param selectedCategories - User-selected categories
 * @param packWords - Words from downloaded content packs
 * @returns Filtered word pool ready for game
 */
export function buildWordPoolWithCategories(
  selectedRegions: Region[],
  selectedCategories: Category[],
  packWords: WordEntry[] = []
): WordEntry[] {
  // Step 1: Combine built-in + pack words
  const builtInPool = buildWordPool(selectedRegions);
  const combinedPool = [...builtInPool, ...packWords];

  // Step 2: Filter by region (words must have at least one selected region)
  const regionFiltered = combinedPool.filter(word =>
    word.regions.some(region => selectedRegions.includes(region))
  );

  // Step 3: Filter by category (if any categories selected)
  if (selectedCategories.length === 0) {
    return regionFiltered; // No category filter, return all
  }

  const categoryFiltered = regionFiltered.filter(word =>
    selectedCategories.includes(word.category)
  );

  // Error boundary: if pool is empty, provide fallback
  if (categoryFiltered.length === 0) {
    console.warn('[buildWordPoolWithCategories] No words match filters. Falling back to regional pool.');
    return regionFiltered.length > 0 ? regionFiltered : getFallbackWord();
  }

  return categoryFiltered;
}

/**
 * Get word count breakdown for display
 */
export function getWordCountBreakdown(
  selectedRegions: Region[],
  selectedCategories: Category[],
  packWords: WordEntry[]
): { total: number; builtIn: number; fromPacks: number } {
  const pool = buildWordPoolWithCategories(selectedRegions, selectedCategories, packWords);
  const builtInCount = pool.filter(w => !packWords.includes(w)).length;
  const packCount = pool.filter(w => packWords.includes(w)).length;

  return {
    total: pool.length,
    builtIn: builtInCount,
    fromPacks: packCount,
  };
}
```

### 2. Content Pack Infrastructure

#### A. Pack Manager (`/utils/packManager.ts` — NEW)

```typescript
import AsyncStorage from '@react-native-async-storage/async-storage';
import type { 
  PackManifest, 
  PackMetadata, 
  ContentPack, 
  InstalledPack 
} from '../types/contentPack';

const MANIFEST_URL = 'https://raw.githubusercontent.com/[username]/desi-imposter-content-packs/main/manifest.json';
const INSTALLED_PACKS_KEY = '@desi_imposter:installed_packs';
const PACK_CACHE_PREFIX = '@desi_imposter:pack:';

export class PackManager {
  /**
   * Fetch available packs from GitHub manifest
   */
  async fetchAvailablePacks(): Promise<PackMetadata[]> {
    try {
      const response = await fetch(MANIFEST_URL, {
        cache: 'no-cache',
        headers: { 'Content-Type': 'application/json' },
      });

      if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
      }

      const manifest: PackManifest = await response.json();
      return manifest.packs;
    } catch (error) {
      console.error('[PackManager] Failed to fetch manifest:', error);
      throw new Error('Failed to load content packs. Check your internet connection.');
    }
  }

  /**
   * Download a specific pack from GitHub
   */
  async downloadPack(
    metadata: PackMetadata,
    onProgress?: (progress: number) => void
  ): Promise<ContentPack> {
    try {
      onProgress?.(10);

      const response = await fetch(metadata.downloadUrl, {
        cache: 'no-cache',
        headers: { 'Content-Type': 'application/json' },
      });

      onProgress?.(50);

      if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
      }

      const pack: ContentPack = await response.json();
      onProgress?.(100);

      return pack;
    } catch (error) {
      console.error('[PackManager] Failed to download pack:', error);
      throw new Error(`Failed to download ${metadata.name}`);
    }
  }

  /**
   * Install pack to AsyncStorage
   */
  async installPack(pack: ContentPack): Promise<void> {
    try {
      // Get existing installed packs
      const installed = await this.getInstalledPacks();

      // Check if already installed
      const existing = installed.find(p => p.packId === pack.id);
      if (existing) {
        // Update existing pack
        const updated = installed.map(p =>
          p.packId === pack.id
            ? {
                packId: pack.id,
                version: pack.version,
                installedAt: Date.now(),
                enabled: p.enabled,
                words: pack.words,
              }
            : p
        );
        await AsyncStorage.setItem(INSTALLED_PACKS_KEY, JSON.stringify(updated));
      } else {
        // Add new pack
        const newPack: InstalledPack = {
          packId: pack.id,
          version: pack.version,
          installedAt: Date.now(),
          enabled: true,
          words: pack.words,
        };
        await AsyncStorage.setItem(
          INSTALLED_PACKS_KEY,
          JSON.stringify([...installed, newPack])
        );
      }

      console.log(`[PackManager] Installed pack: ${pack.name} (${pack.words.length} words)`);
    } catch (error) {
      console.error('[PackManager] Failed to install pack:', error);
      throw new Error('Failed to save pack to device storage');
    }
  }

  /**
   * Get all installed packs from AsyncStorage
   */
  async getInstalledPacks(): Promise<InstalledPack[]> {
    try {
      const stored = await AsyncStorage.getItem(INSTALLED_PACKS_KEY);
      return stored ? JSON.parse(stored) : [];
    } catch (error) {
      console.error('[PackManager] Failed to load installed packs:', error);
      return [];
    }
  }

  /**
   * Enable or disable a pack
   */
  async togglePack(packId: string, enabled: boolean): Promise<void> {
    try {
      const installed = await this.getInstalledPacks();
      const updated = installed.map(pack =>
        pack.packId === packId ? { ...pack, enabled } : pack
      );
      await AsyncStorage.setItem(INSTALLED_PACKS_KEY, JSON.stringify(updated));
    } catch (error) {
      console.error('[PackManager] Failed to toggle pack:', error);
      throw error;
    }
  }

  /**
   * Delete a pack
   */
  async deletePack(packId: string): Promise<void> {
    try {
      const installed = await this.getInstalledPacks();
      const filtered = installed.filter(pack => pack.packId !== packId);
      await AsyncStorage.setItem(INSTALLED_PACKS_KEY, JSON.stringify(filtered));
    } catch (error) {
      console.error('[PackManager] Failed to delete pack:', error);
      throw error;
    }
  }

  /**
   * Get all enabled pack words
   */
  async getEnabledPackWords(): Promise<WordEntry[]> {
    const installed = await this.getInstalledPacks();
    const enabled = installed.filter(pack => pack.enabled);
    return enabled.flatMap(pack => pack.words);
  }

  /**
   * Get storage usage statistics
   */
  async getStorageStats(): Promise<{ packCount: number; totalSizeKB: number }> {
    const installed = await this.getInstalledPacks();
    const totalSizeKB = installed.reduce((sum, pack) => {
      const jsonSize = JSON.stringify(pack.words).length / 1024;
      return sum + jsonSize;
    }, 0);

    return {
      packCount: installed.length,
      totalSizeKB: Math.round(totalSizeKB),
    };
  }
}
```

## 🔄 Migration Strategy

### V1 → V2 Data Migration

**Good News:** No data migration required! V2 is **additive only**.

**Backward Compatibility:**
- Existing V1 data (`/data/*.json`) remains unchanged
- `WordEntry` schema unchanged (already has `category` field)
- AsyncStorage key for used words (`desi_imposter_used_words`) unchanged
- V1 users who update to V2 get all new features without data loss

**Default Behavior for V1 Users:**
1. App updates to V2
2. No categories selected initially → Setup screen prompts "Select at least 1 category"
3. Suggested default: Select ALL categories (maintains V1 behavior)
4. No packs installed initially → 205 built-in words available
5. "Content Packs" button shown on home screen (new entry point)

### Rollout Plan

**Phase 1: Beta Testing (1 week)**
- Deploy to internal testers via TestFlight / Internal Track
- Test category filtering with real gameplay
- Verify pack downloads work on various networks (WiFi, cellular, slow connections)
- Monitor AsyncStorage usage

**Phase 2: Soft Launch (2 weeks)**
- Release to 10% of users via staged rollout
- Monitor crash reports, download success rates
- Gather feedback on category selection UX
- Track pack download metrics

**Phase 3: Full Release**
- Roll out to 100% of users
- Publish initial 4 content packs to GitHub
- Announce new features in update notes
- Create tutorial video for content packs

## ⚠️ Risks & Mitigation

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|------------|
| GitHub rate limiting | High | Medium | Cache manifest locally, implement retry logic |
| Large pack download fails | Medium | Medium | Chunked downloads, resume capability |
| AsyncStorage quota exceeded | Medium | Low | Display storage warning, limit total packs |
| Pack JSON schema drift | Medium | Low | Versioned schemas, validation on download |
| Category selection confusion | Low | Medium | Smart defaults, onboarding tooltip |
| Pack words low quality | High | Medium | Curated packs only (no UGC in V2) |
